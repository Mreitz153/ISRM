# Security

ISRM is a reference model and documentation project. Please do not include secrets, credentials, private personal data or sensitive production-system information in public issues.

Security-related architectural counterexamples and Trust/Control Plane findings may be reported through GitHub issues when they can be disclosed publicly without exposing a live system.
